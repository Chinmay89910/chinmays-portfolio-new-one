- **Skills Matrix**: Dynamic skills display.
- **Education & Experience**: Academic journey and professional experience timeline.
- **Projects Showcase**: Interactive project cards with instant links to Chinmay's GitHub.
- **Spiritual Places**: Visual journey of holy and architectural heritage.
- **Hobbies & Passions**: Image slideshow, cycling, travel, music (tabla), and community service.
